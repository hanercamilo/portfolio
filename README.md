## ¿Qué es este proyecto?

Este repositorio contiene el portafolio personal de Milacho: una aplicación web estática creada con Vite + React + TypeScript y estilo con TailwindCSS. Muestra secciones como "Proyectos", "Servicios", "Habilidades" y un formulario de contacto.

## Características

- Interfaz rápida y responsiva construida con React + TailwindCSS.
- Componentes reutilizables para proyectos, servicios y secciones.
- Modal para detalles de proyectos.
- Optimizada para despliegue estático (Vite).

## Tecnologías

- Vite
- React
- TypeScript
- TailwindCSS

## Cómo empezar

1. Clona el repositorio:

```bash
git clone <repo-url>
cd <repo-folder>
```

2. Instala dependencias:

```bash
npm install
```

3. Inicia el servidor de desarrollo:

```bash
npm run dev
```

4. Construye para producción:

```bash
npm run build
```

5. Previsualiza la build:

```bash
npm run preview
```

Nota: los comandos asumen que usas `npm`. Puedes usar `pnpm` o `yarn` si prefieres.

## Estructura del proyecto

- `index.html` — Entrada principal.
- `src/` — Código fuente (componentes, datos, estilos).
- `public/` — Archivos estáticos.
- `package.json` — Scripts y dependencias.

Ejemplo de carpetas importantes en `src`:

- `components/` — Componentes reutilizables (Header, Hero, ProjectsSection, etc.)
- `data/` — Datos de proyectos, servicios y habilidades
- `utils/` — Utilidades y logos
